# AI Icon Prompts - Sekcja "Dlaczego my"

**Cel:** 4 ambitne, dwukolorowe ikony dla sekcji USP
**Kolory:**
- Primary: #1E3A5F (Steel Blue)
- Accent: #D4A84B (Construction Gold)
**Format:** 512x512px PNG z przezroczystością

---

## Prompt 1: Pełen zakres robót

```
Create a modern, geometric icon representing "full scope of concrete construction".

Visual concept: Isometric or 3D-style layered construction - foundation block at bottom, wall rising up, roof slab on top. Show as unified architectural stack with depth and dimension.

Colors:
- Main structure: #1E3A5F (dark steel blue)
- Accent highlights/edges: #D4A84B (gold)
- Use gold for: top edges, connection points, or one highlighted layer

Style:
- Modern geometric, slight 3D/isometric feel
- Clean vectors, sharp edges
- Transparent background
- Professional industrial aesthetic
- NOT flat - should have visual depth

Output: 512x512px PNG with transparency
```

**Zapisz jako:** `usp-full-scope.png`

---

## Prompt 2: Własny zespół specjalistów

```
Create a modern, geometric icon representing "professional construction team".

Visual concept: Three stylized figures with hard hats, arranged in a triangular or dynamic composition. Center figure prominent. Show teamwork and professionalism.

Colors:
- Figures/hard hats: #1E3A5F (dark steel blue)
- Accent elements: #D4A84B (gold) - use for hard hat brims, badge, or highlight on leader

Style:
- Modern geometric, stylized human forms
- Clean vectors, contemporary look
- Transparent background
- Professional, corporate feel
- NOT cartoon - should feel serious and industrial

Output: 512x512px PNG with transparency
```

**Zapisz jako:** `usp-team.png`

## Prompt 3: Zasięg 4 województw

```
Create a modern, geometric icon representing "regional coverage across 4 areas".

Visual concept: Stylized map pin or location marker with "4" integrated. Could show: pin with radiating circles, or 4 connected location dots, or abstract map with highlighted region.

Colors:
- Main pin/shape: #1E3A5F (dark steel blue)
- Number "4" or highlight: #D4A84B (gold)
- Gold should draw attention to the "4"

Style:
- Modern geometric, bold shapes
- Clean vectors
- Transparent background
- Professional, corporate aesthetic
- The "4" must be clearly visible

Output: 512x512px PNG with transparency
```

**Zapisz jako:** `usp-4-regions.png`

## Prompt 4: Wycena w 24h

```
Create a modern, geometric icon representing "fast 24-hour quote turnaround".

Visual concept: Stylized clock or timer with "24" prominently displayed. Could show: clock face with speed lines, circular timer with checkmark, or abstract time representation with urgency.

Colors:
- Clock/timer body: #1E3A5F (dark steel blue)
- "24" text and speed elements: #D4A84B (gold)
- Gold emphasizes speed and responsiveness

Style:
- Modern geometric, dynamic feel
- Clean vectors, sense of motion/speed
- Transparent background
- Professional business aesthetic
- Should feel fast and efficient

Output: 512x512px PNG with transparency
```

**Zapisz jako:** `usp-24h.png`
